# Changelog - StockDual
Todas las modificaciones, mejoras y arreglos a este proyecto serán documentados en este archivo. El versionado seguirá una estructura SemVer (x.y.z).
## [0.4.2] - Light & Dark Mode Toggle
- **ADDED**: Funcionalidad nativa de cambio de tema Claro/Oscuro desde el header en `MainLayout`.
- **ADDED**: Detección del tema preferido del sistema operativo (Light/Dark mode) a través de un script embebido.
- **CHANGED**: Se mejoró el contraste visual en la grilla (`StockView`) para las filas con discordancias de stock total vs WooCommerce, aplicando un color de fuente rojo intenso (`var(--lumo-error-text-color)`) compatible con los temas Claro y Oscuro.
- **FIXED**: Orden aleatorio en la grilla al editar productos; ahora se fuerza el listado de todos los datos ordenando por `ID` de forma ascendente.

## [0.4.1] - Login UI Glassmorphism
- **CHANGED**: Rediseño completo de LoginView usando Glassmorphism, animaciones radiales de fondo y forzado del tema Lumo Dark.
- **ADDED**: Creación de lógica CSS embebida en Java para asegurar la renderización nativa del login sin anomalías de caché.

## [0.4.0] - WooCommerce API Synchronization & Local Catalog
- **ADDED**: `WooCommerceClient` for basic REST API connections with WooCommerce using Consumer Key/Secret.
- **ADDED**: `WooCommerceSyncService` to handle fetching products from WooCommerce and pushing stock updates in batch mode.
- **ADDED**: "Sincronizar Stock" button in `StockView` to trigger the bidirectional sync process.
- **ADDED**: "Purgar Datos Locales de Prueba" button in `SettingsView` to delete unlinked local products (null `wcId`).
- **ADDED**: Draft product creation in WooCommerce. Local products missing a `wcId` are now automatically pushed as `draft` to WooCommerce during sync, returning the new ID.
- **ADDED**: Mandatory field validation (SKU, Name, Price) in `ProductForm` before saving.
- **CHANGED**: `Product` entity extended with `wc_id` to reliably track Remote vs Local IDs for batch updates.

## [0.3.0] - Grid Column Configuration and Layout improvements
- **ADDED**: `SettingsView` para permitir configurar la visibilidad de cada columna del DataGrid en Desktop y Mobile.
- **ADDED**: Nueva tabla `user_settings` para persistencia backend de las preferencias del administrador.
- **ADDED**: Columna de stock real de WooCommerce (`stock_wc` en DB) para permitir comparación de inventario.
- **ADDED**: Alerta visual CSS sobre las líneas del Data Grid donde haya discordancia entre inventario local y WC.
- **ADDED**: Columna de acciones (Editar, Borrar) como botones estáticos al final de cada fila.
- **CHANGED**: Se agregaron estilos dinámicos al framework y dependencias de VaadinFlow.

## [0.2.0] - 2026-02-20
### Agregado
- **Barra de Filtros y Búsqueda Avanzada**: Implementación de búsqueda por SKU/Nombre/Etiquetas y comboboxes para filtrar productos por Categoría, Marca, Proveedor, Disponibilidad de Stock, Localización y Ordenamiento por precio.
- Nuevas tablas en la base de datos para `brand` y `supplier` vía migración Flyway (V4).
- Adición de campos `tags` y `attributes` en la tabla `product`.
- Uso de `JpaSpecificationExecutor` para realizar cruce de filtros automáticos a nivel de query.

### Arreglado
- Corrección de un error antiguo de sintaxis en `StockView` donde el evento del doble clic en la grilla generaba excepción al referenciar mal el ítem (`item` -> `e.getItem()`).

## [0.1.0] - 2026-02-20
### Agregado
- Documentadas nuevas propuestas para el Módulo de Stock en `ENGINEERING_CONTEXT.md` (Búsqueda, Filtros, Botones de visibilidad, KPIs y Sincronización manual).
