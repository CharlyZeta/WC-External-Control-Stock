## Intent
Corregir riesgos de seguridad críticos identificados en el análisis de código: eliminación de credenciales hardcodeadas (clave de encriptación y contraseña admin) y fortalecimiento de la documentación del Content Security Policy.

## Use Case
**Actor:** Administrador del Sistema / Desarrollador
**Goal:** Asegurar que el sistema StockDual no exponga credenciales por defecto y cuente con una política de seguridad documentada y justificada.

### Main Flow
1. El sistema inicia y carga la configuración de seguridad
2. Si la variable de entorno STOCKDUAL_ENCRYPTION_KEY no está configurada, el sistema lanza una excepción en lugar de usar una clave por defecto
3. Si la variable de entorno STOCKDUAL_ADMIN_PASSWORD no está configurada, el sistema lanza una excepción en lugar de usar una contraseña por defecto
4. La política CSP incluye comentarios detallados que justifican cada directiva

### Alternative Flows
- AF-01: En modo desarrollo, se permite usar valores por defecto pero se registra una advertencia explícita
- AF-02: Si el sistema se ejecuta en contenedor Docker, se espera que las variables de entorno estén configuradas

## Business Rules
- BR-001: La clave de encriptación por defecto debe eliminarse del código fuente
- BR-002: La contraseña admin por defecto debe eliminarse del código fuente
- BR-003: El sistema debe fallar explícitamente si las variables de entorno críticas no están configuradas en entornos no-desarrollo
- BR-004: La política CSP debe incluir comentarios justificativos para cada directiva

## Acceptance Criteria
- AC-001: GIVEN EncryptedStringConverter WHEN se inicializa sin variable de entorno THEN se lanza IllegalStateException
- AC-002: GIVEN EncryptedStringConverter WHEN se inicializa con variable de entorno THEN se utiliza esa clave para encriptar/desencriptar
- AC-003: GIVEN DataInitializer WHEN se ejecuta sin STOCKDUAL_ADMIN_PASSWORD THEN se lanza IllegalStateException
- AC-004: GIVEN DataInitializer WHEN se ejecuta con STOCKDUAL_ADMIN_PASSWORD THEN crea el usuario admin con esa contraseña
- AC-005: GIVEN SecurityConfig WHEN se evalúa el CSP THEN cada directiva tiene un comentario justificativo

## Entities Affected
- EncryptedStringConverter: Eliminación de clave hardcodeada, validación estricta de variable de entorno
- DataInitializer: Eliminación de contraseña hardcodeada, validación estricta de variable de entorno
- SecurityConfig: Mejora de comentarios justificativos del CSP
